# Bestcon Life — сервис управления недвижимостью

**Живой пример:** https://bestcone.vercel.app

## 📋 О проекте

**Bestcon Life** — сервис по управлению недвижимостью. Проект представляет собой **полный рефакторинг и переписывание устаревшего сайта** с нуля на современном стеке.

## 🚀 Технологический стек

### Frontend:
- **Next.js 14** (App Router)
- **TypeScript** (строгая типизация)
- **React Query** (кеширование данных)
- **SCSS Modules**

### Backend:
- **Node.js** + **Express.js**
- **REST API**
